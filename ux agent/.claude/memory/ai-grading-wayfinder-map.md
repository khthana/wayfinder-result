งานทั้งหมดในไดเรกทอรี `ux agent` คือการวางแผนโครงงาน senior project ของนักศึกษา (ทีม 2-3 คน, 1 ปีการศึกษา, เริ่ม 2026-08) ที่สร้างระบบให้ AI Agent ช่วยตรวจงานวิชา UX/UI

แผนที่ wayfinder อยู่ที่ `.scratch/ai-grading-agent/map.md` — **อ่านไฟล์นั้นก่อนเสมอ** เมื่อกลับมาทำงานต่อ ปลายทางคือชุดเอกสารส่งมอบ (spec + wireframe + research report) ไม่ใช่การเขียนระบบจริง

ข้อตกลงสำคัญที่ไม่ปรากฏในโค้ดใด ๆ: calibration loop คือระบบที่ต้อง ship ส่วน RL เป็น experiment เชิงวิชาการที่ยอมให้ล้มเหลวได้โดยโครงงานยังจบ — อย่าปล่อยให้ RL กลืนเวลาของระบบหลัก

ผู้ใช้ต้องการเอกสารส่งมอบฉบับ **ละเอียด** ในรูปแบบ Word/PDF — วิธีสร้างที่ใช้ได้จริงบนเครื่องนี้อยู่ที่ [[doc-build-pipeline-no-word-pdf]] อ่านก่อนสร้างไฟล์

ศัพท์กลางของโครงงานอยู่ที่ `.scratch/ai-grading-agent/CONTEXT.md` — **อ่านก่อนเขียนเอกสารหรือ wireframe ใด ๆ** ข้อที่พลาดไม่ได้: การตรวจของ AI กับของอาจารย์เก็บเป็นคนละก้อน ไม่เขียนทับกัน เพราะส่วนต่างคือสัญญาณเรียนรู้ทั้งหมดของระบบ

`map.md` ใหญ่เกิน token cap ของ Read แล้ว — ต้องอ่านแบบแบ่งหน้าด้วย offset/limit หรือใช้ Grep หาหัวข้อก่อน

บทเรียนเรื่อง session limit: research subagent ของเครื่องนี้ถูกตัดกลางคันบ่อย — **ต้องสั่งทุกตัวให้เขียนไฟล์ผลลัพธ์ตั้งแต่ต้นและอัปเดตระหว่างทาง** ห้ามเก็บผลไว้ในหัวจนจบ ครั้งที่สั่งแบบนี้ agent ตายทั้ง 5 ตัวแต่งานรอด 2,000 บรรทัด ครั้งที่ไม่สั่ง เสียงานทั้งหมด
