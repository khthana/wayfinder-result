เมื่ออาจารย์ส่งเอกสารประกอบมาให้ (เช่น คู่มือตรวจงานของ TA) **อย่าตีความว่าเป็นข้อกำหนดของระบบใหม่** ให้ถือว่าเป็นภาพของกระบวนการปัจจุบันจนกว่าจะได้รับการยืนยัน และถามให้ชัดว่า "อันไหนคือสิ่งที่อยากให้คงไว้ อันไหนคือสิ่งที่อยากให้หายไป"

**Why:** 6 ส.ค. 69 ผมอ่านคู่มือตรวจงานของ TA แล้วสรุปผิดสามข้อรวด — ว่า TA คือผู้ใช้หลัก (จริง ๆ คืออาจารย์ TA แค่ช่วยเพราะปริมาณงาน) · ว่า Figma เป็นส่วนน้อย (จริง ๆ เป็นส่วนน้อย*เพราะ*ตรวจด้วยมือลำบาก ซึ่งคือปัญหาที่ระบบจะแก้) · ว่าต้องรื้อโมเดล rubric ตามรูปแบบในเอกสาร (อาจารย์สั่งให้ยืนตามที่ตัดสินไว้แล้ว) ต้องเขียนตั๋วใหม่สองใบและแก้แผนที่

**How to apply:** หลักที่ใช้ได้ทั่วไป — **รูปแบบของงานในระบบเดิมคือผลผลิตของข้อจำกัดว่าอะไรทำด้วยมือได้เร็ว** สิ่งที่ดู "เป็นส่วนน้อย" ในข้อมูลเก่า อาจเป็นสิ่งที่ถูกกดไว้ด้วยข้อจำกัดที่ระบบใหม่กำลังจะปลด แยกให้ออกระหว่าง *เนื้อของวิชา* (เกณฑ์ ตัวอย่างงาน คลังประโยค ปริมาณงานจริง — ใช้ได้เต็ม ๆ) กับ *วิธีตรวจ* (รูปแบบ rubric ลำดับขั้นตอน — เป็นของชั่วคราว) ดู [[ai-grading-wayfinder-map]]
